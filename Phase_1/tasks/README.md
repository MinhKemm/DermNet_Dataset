# Các module lịch sử

Các module Python và hàm `generate_vqa()` trong thư mục này được giữ để lưu lịch sử; không phải cách sinh VQA đang chọn cho giai đoạn hiện tại.

Dùng [40 prompt v3 trong Phase_1/prompts](../prompts/README_VI.md) với Codex mở từng ảnh thật. Không cần gọi các module ở đây và không cần lấy prompt từ Phase_2/config.

Lượt cập nhật này không sửa runner hoặc hành vi Python cũ. Chia lô subagent, lập lịch và xuất dữ liệu vận hành sẽ được xử lý riêng sau khi có yêu cầu triển khai.
