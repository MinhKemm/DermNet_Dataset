# Task 1: Location Recognition
This task focuses on identifying the anatomical location of a skin lesion.
Prompts available:
- 1.1 Multi_choice: Picks 3 distractors and 1 correct answer.
- 1.2 Judgement: Yes/No question based on `target_flag`.
- 1.3 Short_answer: Direct question.
- 1.4 Fill_in_blank: Blank filling question.
